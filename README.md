# Tactical Drone Defense VR — 3-Drone Swarm Command (Meta Quest / Unity)

Interactive VR tactical defense simulation built in **Unity (OpenXR + XR Interaction Toolkit)** for **Meta Quest 2 / 3 / Pro** (with Desktop WASD + Mouse fallback).

## Your 3 Controllable Drones
1. **ALPHA-RECON (`DroneRole.ReconTracker`)** — Locks onto the advancing hostile threat with a targeting laser, exposing weak points (`+40%` pulse effectiveness).
2. **BETA-AEGIS (`DroneRole.AegisShield`)** — Intercepts between you and the threat, projecting a 3D energy barrier that blocks `80%` of incoming strikes.
3. **GAMMA-PULSE (`DroneRole.PulseInterceptor`)** — Orbits and fires non-lethal EMP/stasis pulses to stagger and neutralize the threat.

## Controls
- **VR / Mouse:** Point & click the **Tactical HUD** to select `All 3` or individual drones (`ALPHA`, `BETA`, `GAMMA`), issue **Orbit & Engage**, **Guard Perimeter**, **Follow / Recall**, or trigger **EMP Burst**.
- **Point-to-Command:** Click/trigger anywhere on the arena floor to send selected drones to that coordinate, or click the threat directly to engage.
- **Desktop Shortcuts:** `WASD` move, `Right-Drag` look, `0/1/2/3` select drones, `O` Orbit/Engage, `G` Guard, `F` Follow, `Space` EMP Burst.
